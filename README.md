# jackal-js

PWA desktop-browser port of SlickJackal with a Java-shaped TypeScript gameplay port in `pwa/src/jackal` and a preserved Java desktop build in `desktop`.

Repository layout:

- `about/` contains the static project page that builds to the production URL root.
- `pwa/` contains the TypeScript browser PWA port.
- `desktop/` contains the archived legacy Java project material and desktop build.
- `scripts/` contains build and release helpers.
- `dist/` is generated by production builds.
- `.release-components/` is generated by component release builds and is not the canonical deploy tree.
- `releases/` is a local staging folder for desktop release zips.

## Web

```sh
npm.cmd run dev
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run build:web
```

The PWA version and cache stamp live in `version.json` and are mirrored into static files that browsers cache.
Production release commands stamp generated artifacts and then restore `version.json`; `npm.cmd run stamp` is only for intentionally updating the tracked stamp.

## Desktop Java

```sh
npm.cmd run build:desktop
npm.cmd run release:desktop
npm.cmd run run:desktop
```

`desktop/src` preserves the Java desktop source and resources. The Maven/fallback desktop build is packaging support and should not be used as a source of new TypeScript gameplay behavior.
The desktop release zip is copied into `releases/` by `npm.cmd run release:desktop`; generated zip files are ignored unless a release process intentionally publishes them.

`npm.cmd run build` builds a full release candidate, verifies it, and then promotes it to `dist/`: the root about page, the PWA under `dist/pwa`, the desktop zip, downloadable copies under `dist/downloads`, and `dist/release.json`.
